下方项目采用方形纸板唱片套：薄侧边朝前，正面印制项目名称，盒面向右后方斜伸。
通过前后纸板、折边与接触阴影表达厚度，避免塑料 CD 盒或悬浮平面卡片的观感。
悬停、键盘聚焦或按下时纸套抬起，黑胶从顶部抽出约三分之一；点击仍直接打开行程。
减弱动态效果时立即呈现选中状态，无过渡动画。集合顶部预留抽出空间，避免裁切。

挂历为只读日期，不映射行程状态或假定出行日期，不提供调度功能。
挂历复用唱片套底图上部未印刷纸纹，采用旧纸、灰绿金属压条、细挂钉、纸页层叠与
左亮右暗阴影，替代纯白网页卡片和蓝色胶囊挂扣。日期保持真实 HTML 文本，今天用
墨色细圈而非实心蓝色按钮表达。验证真实月份和今天标记不变，纹理不得损害日期可读性。

下方方形纸套使用上述按窗口高度约束的尺寸。集合相对页面底部定位，
不跟随背景图片的 cover 裁切坐标，避免宽屏/较矮窗口下唱片落到屏幕外。
横向集合铺满页面宽度，唱片仅在屏幕边缘离开视野，不在内缩容器边缘截断。
保留横向滚动与键盘访问；桌面左侧留出导航操作空间，手机使用小幅边距。
移除唱片标签中央装饰黑点，避免遮住项目名称；浏览器检查尺寸、无黑点及横向滚动。

Trip workspace 成功加载后，将 Trip ID 写入按账号隔离的 sessionStorage 导航指针。
不存名称、私聊或 Profile，不新增服务端业务状态。回到房间时，仅当指针匹配当前
鉴权 API 返回的 Trip 才放上唱盘；所有其他 Trips（含归档）排在下方。首次使用、
新标签页或存储不可用时不猜测最近项目，全部放在下方；退出登录清除指针。
这是本标签页访问历史，不是跨设备最近访问。服务器仍是权限与 Trip 状态的唯一权威。

正常态没有额外控件；登录、加载、错误重试或空态仅有一块小提示牌。
唱片为有名称的语义链接，支持键盘焦点和横向滚动；当前项目名称固定在机身铭牌。
CSS transform 实现旋转，悬停/键盘聚焦暂停；prefers-reduced-motion 禁用动画。
不播放音频，不将旋转解释为后台任务执行。手机裁切场景两侧，保留中心唱片机。

两项设计技能用于约束场景构图、低信息密度、键盘操作和减弱动效。
背景资产与生成提示词见本文顶部；不使用效果图中的虚构项目数据。
动态唱片由 CSS 绘制，与背景使用相同坐标系。没有新依赖、配置或迁移。

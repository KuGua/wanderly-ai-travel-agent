# Provider boundary

`ModelGateway` calls a configured server-side OpenAI, Gemini, or OpenAI-compatible model and returns only structured candidate plans and private conversation replies. Conversation replies normalize Gemini's documented OpenAI-compatible root-level `content` response to the application's `{ reply: { content } }` contract; no other malformed response is accepted. A missing key, timeout, upstream failure, or invalid response fails the request and records a safe agent-run result; it never uses a local substitute.

Travel providers implement typed Flight, Activity, Accommodation discovery, Hotel quote and Ground interfaces. Their result is either `LIVE` with source and capture time, or `UNAVAILABLE` with a bounded reason. Hotel and place adapters accept a complete server-owned `DestinationReference`; no provider port accepts a permissive city-string fallback. `PlanningService` records bounded gaps and fails closed whenever required evidence is absent.

The provider factory exposes live adapters only when their explicit feature flags and credentials are configured. OpenTripMap accommodation discovery is non-price planning evidence with OSM attribution; SerpApi Google Hotels is a separately gated live-quote adapter; Viator uses the official Experiences MCP. Missing credentials, quota, schema drift or ambiguous destination references remain `UNAVAILABLE`: no static price, inventory, location, visa, fixture or booking result is substituted.
